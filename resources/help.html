拾事使用帮助

把想法放进收件箱，把行动安排在合适的一天。

整理和安排

  • 收件箱：尚未归类的任务。使用 ⌘N 新建。
  • 今天：已到开始日期或截止日期的未完成任务；可以安排在今晚。
  • 计划：未来开始或到期的任务。
  • 随时：现在可以着手的任务；某天：暂不安排的想法。
  • 区域代表长期职责，项目代表一个具体目标。项目内部可添加标题分组。
  • 项目页：标题下的“备注”可直接输入并自动保存；双击项目标题或标题分组可直接改名，Return 保存，Escape 还原。
  • 双击边栏里的区域或项目可直接改名：Return 保存，Escape 放弃，留空则保持原名。项目的其它属性用右键“编辑列表…”修改。

项目 → 标题 → 待办 → 检查列表

在项目底部点击“新建标题”，用标题右侧的＋在该分组下新建待办。⌘N 继承当前选中分组。点击待办卡片底部的检查列表图标，直接添加和编辑检查项；Return 连续新增，空行 Return 退出录入，空行 Backspace 删除占位。检查项属于父待办，不是独立任务，勾选不会自动完成父待办。

编辑任务

⌘N 直接在列表内新建，双击任务或按 Return 行内展开。标题前为父待办完成框，备注可直接输入，底部四个图标分别设置日期、标签、检查列表、截止日期。右键“编辑任务…”可设置重复及项目归属等高级属性。点击卡片外或⌘Return保存，Escape取消；输入法组合期间Escape只取消候选。保存失败保留输入。开始日期决定何时开始，截止日期表示最晚何时完成。

标签以逗号分隔。重复支持天、周、月、年及间隔；完成当前任务时生成下一项，检查列表会重置。固定周期以本次开始日期为准；完成后重复以完成时间为准。

项目进度与录入项

项目标题前显示真实完成进度。点击列表下方“显示 N 个录入项”查看已完成和已取消的记录，再次点击可收起。项目标题、完整备注和待办一起滚动，底部工具栏固定；长备注不会撑高窗口，也不使用独立备注滚动条。

项目菜单

标题旁的…提供完成/重新打开、时间、标签、截止日期、移动、重复、复制、删除和分享。复制生成独立项目树；配置重复后完成项目会生成下个周期的副本，旧记录保留。分享仅打开选择器，需要你自行选择服务和发送。删除需要确认，可从废纸篓恢复。

底部任务时间

选中开放待办后，点击底部时间按钮。弹窗提供时间输入、今天、今晚、四周日历翻页、某天、清除安排与添加提醒。支持“明天”“周一”“9月17日”或“2026-09-17”等日期输入，按Return保存。选择日期保存成功后关闭；点击外部或Escape取消，数据不变。未选择任务、只选标题或项目时按钮禁用。

添加提醒可填写日期及HH:mm时间；提醒与任务安排独立。首次主动保存提醒时请求系统通知权限；拒绝或调度失败会提示，本地时间仍保留。完成、取消、删除任务会清理待发通知；手动复制项目清空提醒，重复后继按周期平移。旧Things来源中的提醒时间保持原样，不自动启用。

检查项操作

单击检查项文字即可编辑，圆形按钮勾选完成；选中行保持统一浅灰底色。三横线手柄用于排序，删除在应用底部。底部删除仅影响选中的检查项，完成后会禁用删除按钮，需要重新选择才能继续删除，父待办不会被误删。

选中多个待办

在列表里按住 Shift 点击或用 Shift+↑↓ 选中一段连续的待办，按住 ⌘ 点击可挑选不连续的若干条；⌘A 选中当前列表全部待办。选中超过一条时，标题旁显示“已选 N 项”。

此时“项”菜单、底部工具栏和右键菜单里的安排日期、移动、标签、截止日期、完成、取消、复制、移到废纸篓都会作用于整批。整批变更算一次操作，按一次 ⌘Z 即可全部还原。已完成、已取消和废纸篓中的条目会被自动跳过，不会被批量改写。按 Escape 退出选择。

常用快捷键

  • ⌘N 新建任务；项目内⌘⇧N 新建标题，其他列表⌘⇧N 新建项目；⌘⌥N 新建区域。新建项目始终可从文件菜单访问。
  • ⌘F 快速查找；⌘1–7 切换七个内置列表；⌘/ 显示或隐藏边栏。
  • ⌘A 全选当前列表的待办；Escape 取消选择。
  • 捷径（不按修饰键）：T 今天、E 今晚、O 某天、R 清除安排。在文本输入和卡片编辑状态下这些键仍然是普通字符。
  • ⌘S 时间；⌘⇧M 移动到；⌘⇧T 标签；⌘⇧D 截止日期。
  • ⌘K 完成/重新打开；⌘⌥K 标记为已取消；⌘D 复制待办；⌘⇧Y 归档已完成项；Delete 或 ⌘Delete 移到废纸篓。
  • ⌘Z 撤销；⌘⇧Z 重做。
  • 全局 Control+Option+Space 快速录入（若被其他应用占用，可用文件菜单）。

设置

按 ⌘, 或点击侧栏底部设置，打开常规、云同步、快速输入、提醒事项、日历、数据与备份。常规可更改外观、文字大小、今天分组和 Dock 计数，更改自动保存。完成项可立即、每天或手动归档；手动模式通过“项 → 归档已完成项”或设置中的归档按钮操作，可撤销。

快速输入支持关闭或更换全局快捷键，以及默认添加到收件箱、今天或当前列表。取消保留本次会话草稿，保存失败不清空；退出前有未提交内容会提示。自动填写其他应用内容尚未接入。

系统日历与提醒事项

只有你主动点击授权后才请求系统权限。日历页可选择要显示的日历，在今天/计划中展示只读摘要，计划覆盖含今天的7个本地日，不修改系统事件。提醒事项页可选择列表、预览并勾选导入；与 Things 不同，拾事仅复制标题、备注和截止日期，保留源提醒，不自动删除或完成，重复导入跳过已导入来源。

数据与恢复

任务保存在此 Mac 的 Application Support/Shishi/library.json。使用设置或文件菜单导出备份、恢复备份。导入会先备份当前文件，校验通过后替换。损坏数据库会保护原文件并提示错误。删除的任务可在废纸篓恢复；永久删除前需确认。

从 Things 3 导入

先退出 Things，通过 Finder 复制完整 Things Database.thingsdatabase 包；然后选择“文件 → 从 Things 3 导入…”。确认预览数量和注意事项后导入，原库保持不变。相同原始标识会更新为导出内容，本地独立新建记录保留，导入前自动备份。两个应用之间不会自动同步。

版本范围

拾事是独立 AppKit 实现，不连接 Things Cloud。跨设备同步、iOS/watchOS、Spotlight、URL Scheme、Siri/Shortcuts、邮件入口和自动更新服务未实现。系统日历与提醒事项为用户授权后的本机集成，不等同云同步。原有任务提醒时间保留但尚不触发系统通知。复杂重复模板无法可靠转换时会提示并保留原始规则。
