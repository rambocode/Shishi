# 拾事 · Shishi

参照 Things 3 的组织方式和核心交互实现的独立 macOS 待办应用，**纯 AppKit，不使用 SwiftUI**。SwiftPM 项目，无网络服务依赖；使用系统 SQLite 读取 Things 导出数据。

## 运行与构建

需要 macOS 13+、Xcode Command Line Tools / Swift 5.9+。

```sh
swift test
bash scripts/package.sh release
open build/拾事.app
```

打包结果 `build/拾事.app` 使用本机临时签名，适合本机运行；未进行 Developer ID 签名、公证或公开发布。

普通启动使用 `~/Library/Application Support/Shishi/library.json`。演示数据只通过显式参数创建：

```sh
open build/拾事.app --args --demo
```

`--data-path /absolute/path/library.json` 指定独立数据库；`--qa` 禁用全局热键与窗口位置持久化，供隔离验收使用。不要让两个进程共享同一库；应用会用文件锁拒绝第二个写入者。

## 已实现

- 收件箱、今天/今晚、计划、随时、某天、日志簿、废纸篓。
- 区域、项目、项目标题分组；项目在智能列表显示，已完成/已删除项目可恢复。
- 项目真实圆形进度、已完成/已取消录入项展开，标题旁完整项目菜单、深复制和项目重复。
- 项目标题、长备注和待办整体滚动，底部工具栏固定，完整内容保留且不撑高窗口。
- 项目 → 标题分组 → 待办 → 检查列表；空标题分组有直接新建待办入口。
- ⌘N 行内新建；卡片内直接增删、编辑、勾选检查项，Return 连续添加。日期、标签、截止日期通过底部图标弹窗修改；右键“编辑任务…”处理项目/区域等高级属性。
- 待办重复：卡片 ↻ 图标或右键“重复…”打开面板，选择完成后/每天/每周/每月/每年、间隔，并可一并设置提醒时刻与截止日期天数。完成重复待办会消费当前规则并生成下一个实例；逾期很久的固定周期直接排到今天之后，不再反复生成过去的实例。
- 有效行内草稿在导航、切换编辑对象、关窗和退出前保存；失败保留输入并阻止离开；Escape 明确取消。
- 列表排序、拖到侧栏归类；日期/移动菜单；区域折叠；搜索标题、备注、清单和标签。
- 项目页原地编辑：标题下的备注直接输入，停顿约 0.6 秒自动保存，失焦/切换页面/关窗立即保存；双击项目标题或标题分组即可改名，输入同样实时保存，Return 提交，Escape 还原。
- 视觉：全应用品牌蓝 #1D60C4（含系统控件强调色），左侧面板底色 #F9F9FA，标题分组与检查项选中/编辑为 #D7E5FF 浅蓝圆角底。
- 侧栏双击区域或项目直接在行内改名（Return 提交、Escape 取消、空名保持原名），不再弹出编辑窗口；项目的备注、区域、日期等仍通过右键“编辑列表…”打开完整编辑器。
- 撤销/重做、软删除恢复、本地 JSON 原子保存、导出与恢复备份。
- 从 Things 3 数据库包导入，稳定 ID 合并、原库只读、保留来源元数据和转换提示。
- 多选批量处理：⇧/⌘ 点选、⇧↑↓、⌘A 全选；批量安排日期、移动、标签、截止日期、完成、取消、复制、删除，整批只占一次撤销。
- 对齐 Things 3 的键位：单键捷径 T/E/O/R（今天/今晚/某天/清除），⌘S 时间、⇧⌘M 移动、⇧⌘T 标签、⇧⌘D 截止日期、⌘K 完成、⌥⌘K 取消、⌘D 复制、⇧⌘Y 归档、⌘/ 边栏、Escape 取消选择。捷径在文本输入与卡片编辑态自动让位给字符输入。
- 原生菜单、键盘快捷键、外观跟随系统/浅色/深色、全局快速录入。
- 分类设置窗口：字号、今天分组、Dock计数、立即/每天/手动归档；独立快速输入面板、可配置热键和默认位置。
- 用户主动授权后的系统日历只读摘要与提醒事项预览/勾选导入，保留来源提醒，不自动删除或完成。
- 底部任务时间弹窗：选中开放任务后启用，中文日期输入、四周日历、今天/今晚/某天以及本地系统通知提醒。

## Things 数据导入

用“文件 → 从 Things 3 导入…”选择数据库包，查看数量和转换注意事项后导入。建议遵循 [Things 官方导出说明](https://culturedcode.com/things/support/articles/2982272/)：先退出 Things，通过 Finder 复制完整 `Things Database.thingsdatabase` 包，再导入副本。不要在 Things 运行时只复制 `main.sqlite` 而遗漏 WAL。

也可使用显式本地命令：

```sh
build/拾事.app/Contents/MacOS/Shishi \
  --import-things /absolute/path/Things\ Database.thingsdatabase \
  --data-path /absolute/path/shishi/library.json
```

新任务按 Things 源 ID 的稳定映射写入；重复导入更新相同源 ID 的记录，不创建重复项。**相同源 ID 的本地编辑会被源数据覆盖**，本地独立新增记录和本地删除标记保留；操作前备份目标库。完整逻辑见 [导入说明](docs/things-import.md)。

## 验证与范围

自动测试覆盖规则、持久化、导入、故障恢复、AppKit 编辑控制器、行内草稿和文件锁。真实数据检查需显式设置 `SHISHI_THINGS_TEST_SOURCE`，默认不会访问其他应用数据。

这是独立本地应用，不是 Things 官方客户端。Things Cloud、跨设备同步、iOS/watchOS、Spotlight、URL Scheme、Siri/Shortcuts、邮件入口、自动填写和自动更新服务未实现。系统日历/提醒事项集成需用户主动授权，不等同云同步；提醒仅迁移标题、备注及截止日期，不承诺附件/子任务/位置提醒完整迁移。原始任务提醒时间可导入保留，但尚不发送对应系统通知。没有开放实例的旧重复模板不会自动补造历史任务；复杂重复规则原文保留并提示，不能保证所有 Things 功能完全等价。重复待办按“下一个未来周期”推进，不补记逾期期间错过的每一次。
