# 拾事：Things 3 AppKit 对照实现

- 模式 build；授权：用户要求多 agents 实现、主代理验收，明确 AppKit 禁用 SwiftUI。
- 参照：本机 Things 3.24，已通过 CUA 观察原生窗口、侧栏、项目与任务列表、底部工具条；参考屏幕约935×700点。
- 目标版本 v1 / autonomous：用户明确以 Things 为方向，不另造视觉方向。
- 原生窗口默认1080×760，最小760×560；侧栏约210–230点，主区正文最大约760；SF系统字体；白纸背景、浅灰侧栏、彩色语义图标、行式任务、蓝色项目标题。
- 产品独立命名拾事 / Shishi；仅参照结构/交互，自制图标、合成演示数据，不复制用户数据库及品牌资源。
- 当前独立新目录 outputs/Shishi，没有已有 Git worktree 或代码需迁移，未修改其他仓库。
- 范围：七个智能列表、区域/项目/项目标题、编辑/安排/截止/重复/清单/标签、搜索、撤销恢复、原子持久化、导入导出、键盘入口、打包。
- 外部服务边界：Things Cloud、iOS/watchOS、Apple日历同步、Siri/Shortcuts、邮件入口并无可直接复用的服务与权限；不宣称等同。
- 截图保密：原应用真实数据只在当前观察中查看，不保存到交付源码；候选截图使用独立合成数据。
- 实现4轮以内，自评+独立代码审查，最终主代理验收。

## 验收矩阵
1. 默认空库→新增→编辑→关闭重启持久化。
2. 今天/今晚/计划/随时/某天/收件箱分类与截止日期独立。
3. 任务完成/取消→日志簿；删除→废纸篓→恢复；撤销与重做。
4. 项目/区域/标题/标签编辑，项目任务分组。
5. 搜索标题/备注/标签；日期选择/重复/清单。
6. 最小窗口、空列表、长内容、错误提示、菜单键盘、实际 AppKit 窗口截图。
7. 领域测试、发行构建、签名验证、独立数据目录真实操作。
