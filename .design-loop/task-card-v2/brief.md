# 新建待办卡片与四级层级对齐

模式build，纯AppKit。用户提供四张截图：Things圆角新建卡片、当前表单式卡片差异、检查列表入口悬停状态；随后明确项目→标题→待办→检查列表。

冻结目标：删除默认表单式下拉框、粗焦点框、完整详情/取消/保存按钮排；标题前完成框、备注占位、底部四图标（日期/标签/检查列表/截止）；清单直接在父待办内创建编辑，标题分组下可直接创建对应待办。

新任务使用既有独立SwiftPM工作目录，不存在Git工作树，未改变仓库归属。数据模型不重构、不重新导入真实库，测试使用隔离合成数据。

主代理负责父卡片、层级列表整合、保存边界与实际验收；3个sol/medium子代理分别清单、图标弹窗、标题入口/集成测试。弹窗代理另做只读审查。

验收：空卡片外观，创建空分组，分组下新建父待办，检查项回车连续添加/空行退出/勾选/删除，父状态不受子勾选影响，保存和重载保留ID/关联，元数据草稿不能静默丢弃，输入法Escape不丢草稿。截图来自本任务CUA真实验收窗口，不用静态图代替运行结果。
