# 项目标题拖动排序

项目内的标题表示阶段或类别。拖动标题行可改变分组顺序，其下任务跟随分组显示，任务归属与组内顺序保持不变。双击标题仍可改名。

```mermaid
flowchart LR
    A[拖动可见标题] --> B[当前项目内选择位置]
    B --> C[校验完整标题顺序]
    C --> D[原子保存并刷新分组]
    D --> E[可撤销]
```

标题采用独立 pasteboard 类型，仅支持同一项目列表内排序；日期等系统分组、存档标题和历史任务区域不参与拖动。编辑期间禁止拖动。
`HeadingOperations.reorder` 校验项目状态、重复和遗漏 ID，在候选快照上修改标题 order，验证后交给 Store 持久化；写入失败保留原状态。

底部按钮默认仅显示图标，悬停显示灰色胶囊边框；禁用按钮不显示悬停边框。

拖动放下后，标题与其下任务通过 AppKit 原生行移动平滑过渡（160ms、缓出），保留原控件与选中标题。开启系统“减少动态效果”时直接完成换位。仅在行身份集合不变时执行排序动画，新增、删除或其它结构变化仍使用普通刷新；保存失败不触发换位。

## 拖动反馈与性能

标题使用原生 `NSTableCellView.draggingImageComponents` 提供带阴影的浅蓝浮层，按文字和尺寸缓存图像。原生 gap 让相邻行让位，背景填充浅灰圆角占位；落点对齐分组边界。

落下前先关闭 gap，再提交分组顺序，避免临时间隙与实际行移动冲突；下一轮主队列恢复隐藏源行并同步最终模型。取消也清理临时状态，不写入新顺序。

`RowReorderPlan` 用线性扫描识别 A+B 到 B+A 的连续区块换位，只移动较小的区块。6000 行中移动 2 行分组仅调用 2 次原生行移动。项目任务通过一次 Dictionary 分组直接查取，避免为每个标题重复扫描全部任务。
