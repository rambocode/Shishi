- 项目内只有1条父待办，不把两条检查项计为独立任务。

- projectID、headingID及清单ID保持；再次展开看到两条原检查项。
- 实际截图可见项目、标题、父卡片、检查项四级关系和底部四图标，截图位于本任务原生操作输出。
