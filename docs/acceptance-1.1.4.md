# 1.1.4 统一隐藏焦点外圈

全应用窗口首次成为key时统一关闭原生view/cell焦点环；窗口更新只处理当前first responder及其field editor所属控件，不遍历全树。动态弹窗与后来创建的输入框也适用，不改系统设置或其他应用。快速查找明确关闭焦点环，移除任务勾选框自绘的外部焦点圈；保留实际焦点、输入光标、选区和行高亮。

4项针对性测试通过（FocusAppearanceTests及ProjectSpaceTests），验证控件状态、动态文本编辑器选区和键盘新建不受影响。Release构建/本机签名通过；QA实机⌘F后输入test，搜索框有光标、可输入但无外部蓝圈。未重跑完整测试集，也未声称每种系统弹窗均逐个实机走查。

应用包与ZIP已更新，正式旧进程未强制重启；重启后生效。未修改真实用户数据、未提交或发布。
