# 1.2.0 底部任务日期与提醒

2026-09-16，build11，纯AppKit。

## 实现

底部时间仅选择开放任务后启用，不默认修改项目。选中任务的上下文工具栏加入时间入口，保留移动、删除和更多。点击显示按钮选中底色及上方深灰紧凑弹窗，提供时间输入、今天/今晚图标、四周日历翻页、某天、添加提醒。选中日期高亮，过去日期禁用，日期和提醒时间有校验。

提交核对原任务和当前选择，保存成功才关闭；失败保留，外部点击/Escape取消无变更。切换任务关闭旧弹窗。提醒独立字段兼容旧库，本地保存后用户主动提交请求系统授权；同一时间可再次保存重试，日期选择本身不申请权限。任务行显示当前提醒时间。

通知使用稳定任务ID，跟随标题/日期更新、完成/取消/删除、撤销与恢复；启动清理遗留队列及恢复已明确保存提醒，不启用旧Things提醒metadata。最多64项未来通知，容量/拒绝/系统错误明确反馈。手动副本清空提醒，重复后继按周期平移。
