# 1.1.1 项目整体滚动

2026-09-16，build7。以用户最新Things截图为准，替换此前160pt项目备注独立滚动。

## 实现

项目标题、完整备注、标题分组、任务表和历史开关处在统一外层滚动文档，底部工具栏固定。备注保持可选文字，项目模式无内层滚动条，滚轮向外层传递。表格仍使用真实任务行索引，没有插入虚拟标题行；高度随卡片及检查列表更新。同路由刷新保留滚动位置，切路由回顶部；新建和编辑可定位到文档中的任务。非项目描述保留原有限高控件，但主区统一使用外层滚动布局。

## 验证

- 全量146项测试通过，0失败、0跳过，包含授权Things数据库副本只读测试。
- 新增3项项目滚动回归：统一文档/父窗口不增高、刷新/切页/编辑可见性、缩宽重排和短备注收缩。
- 首轮隐藏窗口fixture没有在设置contentViewController后分配尺寸，导致clip零高及不可见cell。修正测试尺寸分配后通过，没有强制创建cell或跳过断言。
- 真实QA：180段备注完整展开；滚轮位于备注上也滚动整个项目，标题离开视口，第180段后显示任务；侧栏与底部工具栏不动。
- 双击末尾任务能展开并聚焦标题；返回顶部后⌘N会自动滚到新草稿位置。验收新草稿已取消，无真实用户任务变更。
- 最小窗口760pt宽复验：备注自动换行，可滚到底，待办和底部按钮不被遮挡。
- Release构建、临时签名校验通过，正式窗口正常重启，ZIP更新。
