# 项目、标题、待办和检查列表

## 层级

```text
项目
└── 标题分组（Heading）
    └── 待办（Todo）
        ├── 检查项（ChecklistItem）
        └── 检查项（ChecklistItem）
```

标题是项目中的分组，不是可以完成的任务。检查列表是父待办的步骤；勾选检查项不自动完成父待办，也不会新建独立Todo。原有不带标题分组的待办仍保留在项目顶部，不为此次UI更新移动用户数据。

## 操作

1. 在项目页面底部点击“新建标题”，创建项目内标题分组。没有待办的空分组也显示。
2. 点击标题右侧“＋”，在该标题下新建待办。选中分组或分组内待办后，⌘N 继承所在分组。
3. 在待办卡片中填写标题和备注；点击底部检查列表图标，直接在父待办下面输入检查项。
4. 检查项输入后按 Return 新增下一行；空行 Return 结束连续录入。空行 Backspace 删除占位。行尾三横线手柄拖拽排序；选中检查项后，在应用底部删除或使用移动菜单上/下移。删除后清空选择，需重新选择才能继续删除。
5. 日期、重复、标签、截止日期从同一卡片的图标弹窗修改。检查列表图标悬停显示文字。
6. 重复用卡片上的 ↻ 图标或列表右键“重复…”设置：先选重复方式（完成后 / 每天 / 每周 / 每月 / 每年），再填间隔，必要时勾选提醒时刻和截止日期天数。没有开始日期的待办设为重复时自动安排到今天，否则后续实例没有锚点。
7. 点击卡片外、切换列表、⌘Return、关窗或退出时保存有效草稿。Escape 明确取消；组合输入中的 Escape 留给输入法，不取消整张卡片。

## 保存规则

- 四个层级以稳定 ID 关联，允许两个标题文字相同但 ID 不同。
- 新卡片是草稿，保存前不写空白待办；清单中的空白占位不会写入数据库。
- 已填写日期/标签等元数据但没有标题时，提示补标题，不能作为空白草稿静默丢弃。
- 保存失败保留卡片和输入，禁止离开造成丢失；取消不改变原数据库。
- 本次改动不更改 Things 原数据，不重新导入，也不把验收示例写入正式数据库。

## 实现边界

`InlineTaskEditorView` 编排父卡片，`InlineChecklistView` 管理检查项及键盘输入，`CardDatePopover`/`CardTagsPopover`/`TaskRepeatPopover` 只回调草稿值（重复面板产出 `TaskRepeatSettings`，由 `applied(to:)` 统一换算开始日期、提醒和截止日期），`ProjectHeadingController` 创建/改名标题；`TaskListController` 统一管理分组展示、行高和保存边界。底层 `TaskStore` 继续原子保存整个有效快照。
